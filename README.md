# Coaching WoW

Tableau de bord de coaching Mythique+ et raid (Drek'Thar EU), construit à partir des logs publics [Warcraft Logs](https://www.warcraftlogs.com).

Chaque clé et chaque boss sont comparés à 5 joueurs de la même spé du top 100, sans buff externe, même niveau de clé ou même difficulté, niveau d'objet à ±3, en priorité avec le même type de tank et la route la plus proche.

Le site est statique : `index.html` affiche les données de `data.js`, avec les icônes de sorts dans `icons/`.
